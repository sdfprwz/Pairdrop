About PairDrop Clone

PairDrop Clone is an open, P2P file sharing platform inspired by PairDrop.net & Snapdrop.

  • 🔐 End-to-end encrypted via WebRTC DataChannel (DTLS)
  • 🚀 No server storage — files go directly between devices
  • 🏠 Peer discovery via WebSocket signaling server + rooms
  • 📱 Works across phones, tablets, laptops

How it works: Signaling server only exchanges SDP/ICE to establish WebRTC. Actual file bytes travel P2P. If WebRTC fails, a relay fallback via server is available.

Built with Node.js + Express + ws + WebRTC. STUN: Google.
